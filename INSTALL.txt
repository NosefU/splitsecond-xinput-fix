Split/Second gamepad fix
========================

[RU]

Управление геймпадом во всех меню, иконки кнопок Xbox вместо клавиш в подсказках
меню, на заставке и в подсказках во время гонки.

Работает с коробочной и со Steam-версией игры (установщик проверяет
SplitSecond.exe и откажется работать с другой версией). Нужен оригинальный, не
изменённый data/resident.ark.

Состав
  ssfix-install.exe   установщик для Windows (архив *-windows.zip)
  ssfix-install       установщик для Linux / Steam Deck (архив *-linux.tar.gz)
Всё нужное (DLL фикса и правки файлов игры) встроено в установщик.

Windows
  1. Распакуйте архив куда угодно и запустите ssfix-install.exe.
     Windows попросит права администратора. Если SmartScreen скажет, что
     приложение не распознано: "Подробнее" -> "Выполнить в любом случае".
     Установщик найдёт игру (Steam-версию и установленную с диска), покажет
     список копий с состоянием фикса и спросит, что сделать:
     i - установить, r - переустановить / обновить, u - удалить.
     Если вашей копии нет в списке, скопируйте ssfix-install.exe в папку игры
     (рядом с SplitSecond.exe) и запустите там - тогда он сразу ставит фикс в
     эту папку. Или передайте папку игры:
         ssfix-install.exe "C:\Games\Split Second"
  2. Запустите игру. Управление один раз сбросится на раскладку, под которую
     рассчитан фикс.

Steam Deck / Linux (Proton)
  1. В режиме рабочего стола распакуйте архив куда угодно.
  2. Откройте терминал в этой папке (в Dolphin: правой кнопкой по пустому месту ->
     "Открыть терминал") и выполните:
         ./ssfix-install
     (если система ответит "Permission denied", сначала: chmod +x ssfix-install)
     Установщик найдёт игру через Steam (Steam-версию и ярлыки на SplitSecond.exe),
     покажет список копий с состоянием фикса и спросит, что сделать:
     i - установить, r - переустановить / обновить, u - удалить.
     Если вашей копии нет в списке, укажите её папку (путь ниже - только пример):
         ./ssfix-install "/home/deck/Games/Split Second"
  3. В Steam Input используйте обычную раскладку геймпада, клавиши не нужны.
  4. Запустите игру. Управление один раз сбросится на раскладку фикса.
  Установщик сам разрешает Proton загружать DLL фикса: прописывает
  переопределение в префикс игры (Steam-версии или ярлыка). Если он сообщит, что
  не смог (игру ещё не запускали или она запущена), запустите или закройте игру и
  повторите установку, либо добавьте в свойства игры -> Параметры запуска:
         WINEDLLOVERRIDES="xinput1_3=n,b" %command%

С геймпадом Xbox 360 игра сама управляет меню; фикс это замечает и только
показывает иконки кнопок.

Геймпад
  В меню:   D-pad / левый стик - выбор, A - подтвердить, B - назад,
            X / Y - дополнительные действия из строки подсказок, Start - назад
  В гонке:  по настройкам игры (RT - газ, LT - тормоз, левый стик - руль,
            A / B - PowerPlay 1 / 2 уровня, Y - камера), Start - пауза

Удаление
  Запустите в папке игры "Uninstall gamepad fix.bat" (Windows) или
  uninstall-gamepad-fix.sh (Linux / Steam Deck) - установщик кладёт их туда сам.
  Либо: ssfix-install --uninstall "<папка игры>".
Архив восстанавливается байт в байт по data/resident.ark.ssfix, DLL удаляется
(прежняя xinput1_3.dll возвращается из xinput1_3.dll.bak), скрипт удаления и
папка ssfix\ тоже удаляются.

Steam: смена языка игры, обновление или проверка целостности файлов заменяют
SplitSecond.exe и data/resident.ark. Перед сменой языка удалите фикс, после -
установите снова. Если файлы уже заменены, просто запустите установщик ещё раз.

Лог: Documents\ss_xinput_fix.log (в Proton - внутри префикса игры,
.../pfx/drive_c/users/steamuser/Documents/)


[EN]

Gamepad navigation in all menus; Xbox button icons instead of keyboard keys in
the menu hints, on the title screen and in race hints.

Works with the boxed and the Steam version of the game (the installer checks
SplitSecond.exe). Needs the original, unmodified data/resident.ark.

Windows: unpack anywhere, run ssfix-install.exe and allow administrator rights.
It finds the game (the Steam version and the one installed from disc), lists
the copies with the state of the fix and asks what to do: i - install,
r - reinstall / update, u - uninstall. If your copy is not listed, put
ssfix-install.exe next to SplitSecond.exe and run it there (it then installs
into that folder straight away), or pass the game folder as an argument.
Then start the game.

Steam Deck / Linux: unpack anywhere, open a terminal there (Dolphin:
right-click -> Open Terminal Here) and run
    ./ssfix-install
It finds the game through Steam (the Steam version and shortcuts to
SplitSecond.exe), lists the copies with the state of the fix and asks what to
do: i - install, r - reinstall / update, u - uninstall. If your copy is not
listed, pass its folder: ./ssfix-install "/path/to/your/Split Second".
Use a plain gamepad layout in Steam Input. The installer enables the DLL in the game's Proton prefix itself;
if it reports that it could not, add
    WINEDLLOVERRIDES="xinput1_3=n,b" %command%
to the game's launch options in Steam.

On the first start the controls are reset once to the layout the fix expects.
Steam: changing the language, an update or verifying the game files replace
SplitSecond.exe and data/resident.ark. Uninstall the fix before changing the
language and install it again afterwards; if the files are already replaced,
just run the installer again.
To uninstall, run "Uninstall gamepad fix.bat" (Windows) or
uninstall-gamepad-fix.sh (Linux) in the game folder; the archive is restored
byte for byte.
