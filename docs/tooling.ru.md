# Инструменты и форматы

[English](tooling.md) | **Русский**

Для исследовательских скриптов нужны Python 3 с `numpy`, `Pillow` и `capstone`; для сборки
роликов — Java и [JPEXS FFDec](https://github.com/jindrapetrik/jpexs-decompiler).

| Файл | Назначение |
|---|---|
| `tools/ark.py` | чтение `.ark`: `ark.py list <архив>`, `ark.py extract <архив> <хэш> <файл>` |
| `tools/arkdump.c` | быстрая распаковка всего архива в `<хэш>.bin` (`cc -O2 -o arkdump tools/arkdump.c`) |
| `tools/ark_patch.py` | ручная замена одной записи архива (для экспериментов; установщик делает то же с откатом) |
| `tools/mkdiff.py` | генерация SSDF-диффа между оригинальной и изменённой записью (с самопроверкой) |
| `tools/make_diffs.sh` | полная пересборка `patch/*.ssdf` из оригинального архива |
| `tools/embed.py` | упаковка DLL и диффов в `payload.h` для установщика |
| `tools/swf.py` | минимальное чтение/запись тегов SWF/GFX, генерация простых фигур |
| `tools/sxet.py` | распаковка наборов текстур `SXET` в PNG (имена — из соседнего списка имён) |
| `tools/padicons.py` | сборка `Prompt_Bar.gfx` с иконками Xbox |
| `tools/pressstart.py` | подготовка `FE_pressStart_Overlay.gfx` (клип с кнопкой A, имя текстового поля) |
| `tools/memscan.py` | разбор снимков памяти из исследовательской сборки (`ss_mem.bin`) |
| `tools/ssdis.py` | помощники для дизассемблирования дампа расшифрованного exe (`ss_dump.bin`) |

## Формат `.ark`

Заголовок из 6 `u32` (версия `0x10000`, размер таблицы, число записей, …), с `0x18` — записи по
20 байт: `flag, offset, csize, usize, hash`. Записи отсортированы по хэшу; имена файлов хранятся
только как хэш.

- `flag = 1` — данные сжаты: `u32` исходный размер и поток LZSS (кольцевой буфер 4 КБ, заполнен
  нулями, начальная позиция `0xFEE`; байт флагов, ссылка — 12 бит смещения и 4 бита длины + 3).
- `flag = 0` — данные как есть.

Архивы из зашифрованного файла `dfe` игра при запуске расшифровывает в
`%TEMP%\SplitSecond_Data_DFE\` — там трассы Nemesis в том же формате.

## Наборы текстур (`SXET`)

`u32 "SXET"`, `u32 0xC`, …, в `+0x10` — число текстур, с `0x28` — записи по `0x40` байт (формат,
ширина, высота, хэш). За ними таблица `u32 total, u32 0, u32 count, u32 x` и `count` троек
`(запись, 0, смещение данных)`; данные — блоки `[u32 размер][DDS-файл]`. Имена текстур лежат
отдельным файлом-списком в том же порядке. Наборы для меню (CommonUI) несжатые, BGRA 32 бита.

## Ролики Scaleform

`.gfx` — это SWF (без сжатия, сигнатура `GFX`, версия 8) с расширениями Scaleform: внешние
картинки (`DefineExternalImage`, тег 1001), `ExporterInfo` (тег 1000) с именем ролика. FFDec
открывает их напрямую; скрипты в FFDec адресуются как `/DefineSprite_<id>/frame_<n>/DoAction`.

## Исследовательская сборка (`make diag`)

Прокси с `-DDIAG` дополнительно пишет в `Documents`:

- `ss_mem.bin` — снимки секций `.data`/`Sdata` exe каждые 0,5 с (разностные); `tools/memscan.py`
  превращает их в массивы для поиска переменных состояния (так найдены флаги меню и паузы);
- `ss_dump.bin` — образ exe из памяти при первом входе в гонку (код уже расшифрован SecuROM),
  для дизассемблирования через `tools/ssdis.py`;
- в лог — нажатия клавиш, активность геймпада и привязки управления из профилей игры.
